# 字体的魅力 · The Charm of Type

> **一个面向大众的开源互动字体图谱。** 输入一句话，亲眼看见中文与英文字形如何改变语气、节奏和阅读感受。

《字体的魅力》不是字体清单，也不是一个只给设计师使用的工具。它从“看见”开始：认识分类、观察字形、比较同一段文字、理解真实语境，并逐步建立能够带回日常阅读的视觉判断。

## 为什么开源

字体每天都在影响我们阅读、行走、购买和理解信息，但有关字体的知识常被隔在专业术语、版权信息和昂贵课程之外。我们希望用公开的代码、清晰的来源和可参与的编辑流程，把字体美学带回大众的日常观察。

这是一项长期的公共教育项目。所有内容都应尽量做到**对象明确、来源透明、语言易懂、可被修订**。

## 运行项目

```bash
pnpm install
pnpm dev
```

然后打开终端显示的本地地址。生产构建可使用：

```bash
pnpm run check
pnpm run build
```

## 内容与来源

网站中的基础分类与术语参考 Google Fonts Knowledge、Adobe、Monotype 等公开教育资源；每个后续专题都会在页面中标注编辑者、更新时间、参考来源与素材说明。详见 [内容来源与编辑规范](CONTENT_SOURCES.md)。

请注意：字体文件、案例图片、品牌商标和网站截图的使用条件并不相同。我们不会仅因素材可在互联网上看到，就默认其可被再发布。

## 如何参与

目前最需要的贡献有三类：发现并核对勘误、推荐可追溯的真实字体案例、协助中英文术语与说明的翻译润色。开始前请阅读 [贡献指南](CONTRIBUTING.md) 和 [行为准则](CODE_OF_CONDUCT.md)，也可以直接从 [Issues](https://github.com/tom61-bl/font-magazine-v1/issues) 发起一条建议。
