# 对标样本范围

本轮不以网站流量、商业规模或视觉风格作为唯一标准，而从“如何让大众愿意进入、理解、复访并参与文化知识”出发，分别观察内容权威性、叙事与互动、真实案例、开放协作和社区传播。

| 样本 | 对标维度 | 研究原因 |
| --- | --- | --- |
| Google Arts & Culture | 面向大众的文化入口与视觉叙事 | 观察大规模文化内容如何降低第一次进入的门槛。 |
| Google Fonts Knowledge | 字体知识的课程化表达 | 观察可复用的字体术语、练习和学习模块。 |
| Letterform Archive | 专业藏品、语境与编辑深度 | 观察字体历史如何从“好看”走向可验证的文化叙事。 |
| Fonts In Use | 真实案例、分类与社群编辑 | 观察字体知识如何通过真实应用场景建立持续内容库。 |
| The Met Heilbrunn Timeline | 引用、时间线与公共教育 | 观察博物馆级知识页面如何兼顾可读性与研究出处。 |
| The Public Domain Review | 面向公众的人文叙事 | 观察有观点的文化文章如何保持可读、可信和可分享。 |
| The Book of Shaders | 开源互动教材 | 观察交互式知识产品的开源文档、学习路径与社区势能。 |
| GitHub Community Health Files | 开源项目的贡献与信任基础 | 观察 README、LICENSE、议题和贡献规范如何降低参与门槛。 |
