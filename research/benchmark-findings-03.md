# 标杆发现（三）：GitHub 发现、信任与增长的基础设施

## 当前起点

截至 2026-08-20，原始公开仓库 `tom61-bl/font-magazine-v1` 的公开元数据为：0 stars、0 forks、0 watchers；已启用 Issues，但没有 Topics、License 或 Discussions。GitHub Community Profile 的健康度为 **28%**，并确认缺少 CODE_OF_CONDUCT、CONTRIBUTING、issue template、pull request template 与 LICENSE。它并不意味着内容没有价值，只说明 GitHub 尚未获得足够的“项目是什么、为什么值得关注、如何参与”的可发现与协作信号。[1]

作为对照，开源互动教材 The Book of Shaders 的仓库公开显示 6,983 stars、754 forks、233 watchers，并设置了清晰描述与多个主题标签。这个对照不能被理解为“添加标签就会获得星标”；更合理的结论是，持续有用的教材、可理解的定位和可被发现的元数据会共同降低传播与参与的摩擦。[2]

## Topics 与社交预览

GitHub 官方说明，Topics 会出现在仓库主页，并能帮助用户按主题探索、发现相关项目和贡献机会；每个仓库最多可添加 20 个主题。仓库社交预览图可提升链接在社交平台上的辨识度，推荐尺寸为 1280 × 640 px。[3] [4]

对项目而言，应将下列 Topics 作为首批候选，而不是机械堆词：`typography`、`type-design`、`font`、`design-education`、`visual-literacy`、`chinese-typography`、`web-typography`、`interactive-learning`、`cultural-education`、`open-source`。

## 开源项目首先需要“被信任”

GitHub 的社区档案会检查 README、CODE_OF_CONDUCT、LICENSE、CONTRIBUTING 等推荐文件。Open Source Guides 进一步指出：README 应说明项目的作用、价值、启动方式与支持入口；CONTRIBUTING 应说明可以参与什么；LICENSE 不是装饰，而是开放使用、修改和再分发的法律基础。[5] [6]

对文化科普项目还应额外补充：内容来源与图片/字体授权说明、编辑事实核查规则、翻译规范、案例提交的版权确认以及“什么内容不会收录”的边界。
